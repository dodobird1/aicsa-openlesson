## Text and code

A page can be a little more than a page. Write in **Markdown**, add a code example, and bring in an interactive component wherever it makes sense. This is a framework preview—not part of your course.

```python
# A place for your code examples.

    return f"Hello, {name}!"

print(say_hello("curious mind"))
```

## Formulas

Use LaTeX-style notation right inside a lesson. Inline math such as $a^2 + b^2 = c^2$ fits into a sentence; display equations get a little room of their own.

$$
\frac{1}{n} \sum_{i=1}^{n} x_i = \bar{x}
$$

$$
\begin{aligned}
f(x) &= x^2 + 2x + 1 \\
     &= (x + 1)^2
\end{aligned}
$$

## Code exercises

Students write code right in the lesson, reveal hints one at a time, and submit for AI grading against a visible rubric. Grading behavior is controlled by a server-side preset (`code-grader` by default).

<CodeExercise
  id="showcase-code"
  title="Fix the greeting"
  prompt="This program should print a greeting, but it has two mistakes. Fix them so it compiles and prints Hello! The grader will check each rubric item."
  starter={`public class Greeter {
    public static void main(String[] args) {
        System.out.println(Hello!)
    }
}`}
  rubric={['The string Hello! is wrapped in double quotes', 'The println statement ends with a semicolon', 'The program prints Hello!']}
  hints={['Without quotes, the compiler treats Hello! as code, not text', 'Every complete statement ends with a semicolon']}
/>

## Vibe coding

An IDE-style pairing of a student-owned editor and an AI coach. The coach receives the current code as context with every question, points at lines and suggests fixes—but it never edits anything. There is no apply button: the code only changes when the student types the change.

<VibeCoding
  id="showcase-vibe"
  title="调试这段程序"
  task="这段程序应该打印 1 到 5 的和，但它无法编译。找出并修复所有错误——问 AI 教练问题可以，但改动要自己动手。"
  starter={`public class Sum {
    public static void main(String[] args) {
        int total = 0
        for (int i = 1; i <= 5; i++) {
            total += i
        }
        System.out.println("Total: " + total)
    }
}`}
/>
