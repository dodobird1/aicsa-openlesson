## 一条线摊开成一张表

成绩单、座位表、棋盘——真实数据常是**二维**的。Java 用「数组的数组」表达：`int[][]`（二维数组，2D array）。

```java
int[][] grid = new int[3][4];     // 3 行 4 列的一张表
```

把它想成座位表：**3 行**，每行 **4 个座位**。初始化列表版：

```java
int[][] table = {
    {1, 2, 3},
    {4, 5, 6}
};                                  // 2 行 3 列
```

## 访问与两种 length

```java
grid[1][2] = 99;        // 第 1 行、第 2 列的格子（行列都从 0 起）
int x = grid[1][2];     // 读
```

二维数组有**两个长度**，这是本课的头号考点：

| 表达式 | 含义 |
| --- | --- |
| `grid.length` | **行数**（第一维） |
| `grid[0].length` | 第 0 行的**列数**（第二维） |

记忆法：`grid` 本身是「行的数组」（所以 length 是行数）；`grid[0]` 是一行，是个普通一维数组（所以 length 是这行的列数）。

## 双重遍历：外层行、内层列

遍历一张表 = 嵌套循环（第 20 课的老朋友）：**外层走行，内层走列**——

```java
for (int row = 0; row < grid.length; row++) {           // 每一行
    for (int col = 0; col < grid[row].length; col++) {  // 这一行的每一列
        System.out.print(grid[row][col] + " ");
    }
    System.out.println();                                // 一行打完换行
}
```

注意内层条件用 `grid[row].length`（**当前行**的列数）——虽然 AP 不考锯齿数组（每行列数不同的表格，考纲边界声明不考），写 `grid[row].length` 是通用好习惯。

## 每日一虫 🐛：拿行数当列数

```java
int[][] grid = new int[3][5];    // 3 行 5 列
int count = 0;
for (int row = 0; row < grid.length; row++) {
    for (int col = 0; col < grid.length; col++) {   // 虫在这：内层也用了行数 3
        count++;
    }
}
```
