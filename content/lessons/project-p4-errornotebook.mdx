## 系统设计

```
ErrorNotebook（指挥调度）
├── main：读入题库文件 → 展示今日应复习的题 → 模拟一轮复习
│
Question（一道错题的自我管理）
├── 字段：title（题目）、topic（错因分类）、wrongCount（答错次数）
├── 构造器 + getter
└── needsReview(today)：wrongCount 越大越优先——本课简化为「全部待复习」
```

**题库文件**（bank.txt）每行一道题，格式：`题目,错因`——split 流水线的实战现场：

```text

```

## readBank：本项目的灵魂方法

把文件读成 `ArrayList<Question>`——**这段是考纲代码**（Quick Reference 上的 File + Scanner + split 全员出场）：

```java
public static ArrayList<Question> readBank(String fileName) throws IOException {
    ArrayList<Question> bank = new ArrayList<Question>();
    File file = new File(fileName);
    Scanner in = new Scanner(file);
    while (in.hasNext()) {
        String line = in.nextLine();
        String[] parts = line.split(",");
        bank.add(new Question(parts[0], parts[1]));
    }
    in.close();
    return bank;
}
```

<Callout title="P4 特有铁律">这段代码可以让 AI 教练帮你审查、讲解，但**审查通过后必须手抄一遍进笔记**——它是考试范围内的代码（4.6 直考），不享受「项目代码可以 AI 辅助」的待遇。手写读文件骨架，本来就是你的必备技能。</Callout>

## 验收与抽查

1. **跑通**：本地 bank.txt 三行题 → 打印三道题 + 错因统计；
2. **考纲代码手写**：readBank 白纸默写（import、throws、while + hasNext、split、close 一个不能少）——这是验收的硬指标；
3. **抽查讲解**：讲清 split(",") 之后 parts[0] 和 parts[1] 各是什么、为什么 Question 构造器里用 this。
