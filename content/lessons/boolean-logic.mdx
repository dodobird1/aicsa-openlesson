## 欢迎来到 Unit 2

从这课起进入考试第二大板块（权重 25–35%）：**选择与迭代**。而这一切的地基是一种你早就见过、但还没正式认识的类型——boolean。

## 布尔：只有两个值的世界

`boolean` 类型只有两个值：`true` 和 `false`。它不是数字也不是字符串——不加引号、不大写（`True` 是错的，Python 才那么写）。

关键认知：**每个比较表达式本身就是一个值**，类型是 boolean：

```java
int score = 85;
boolean passed = score >= 60;      // passed 的值就是 true
System.out.println(7 > 10);        // 直接打印 false
```

`score >= 60` 不是「一个问题」，它是一个**答案**——可以存进变量、可以打印、可以传给方法。这个认知是本课的门槛。

## 六个关系运算符

| 运算符 | 含义 | 例（x = 5） | 结果 |
| --- | --- | --- | --- |
| `==` | 相等 | `x == 5` | `true` |
| `!=` | 不等 | `x != 5` | `false` |
| `<` `>` | 小于 / 大于 | `x > 3` | `true` |
| `<=` `>=` | 小于等于 / 大于等于 | `x <= 5` | `true` |

<Callout title="== 的两个陷阱">一、`=` 是赋值，`==` 是比较——`if (x = 5)` 在 Java 里直接编译错误，这是好事。二、比较 String 内容用 equals 不用 ==（第 13 课的老朋友，Unit 2 还会反复遇到）。</Callout>

## 逻辑三剑客：&&、||、!

真实条件常常是复合的：「分数及格**且**出勤过半」。三个逻辑运算符负责组合布尔值：

| 运算符 | 读作 | 结果为 true 的条件 |
| --- | --- | --- |
| `a && b` | 且（AND） | 两个都是 true |
| `a \|\| b` | 或（OR） | 至少一个 true |
| `!a` | 非（NOT） | a 是 false |

经典应用——判断「score 在 0 到 100 之间」：

```java
boolean valid = score >= 0 && score <= 100;   // 数学课的 0 ≤ score ≤ 100 不能照抄！
```

数学的连写 `0 <= score <= 100` 在 Java 里是编译错误——必须拆成两个比较用 `&&` 连接。这是从数学迁移到编程的第一个坑。

## 短路求值：聪明的 && 和 ||

`&&` 和 `||` 从左到右算，**一旦结果已定就不再看右边**——这叫短路（short-circuit）：

- `false && 任何` → 左边是 false，直接 false，右边不执行；
- `true || 任何` → 左边是 true，直接 true，右边不执行。

短路不是偷懒，是护身符：

```java
if (count != 0 && total / count > 10) { ... }
// count 为 0 时：左边 false，右边的除法根本不会执行——避免了除以零
```

## De Morgan 律：NOT 的分发法则

感叹号想进括号，要翻转里面的运算符——**且变或，或变且，比较符反向**：

```java
!(a && b)   等价于   !a || !b
!(a || b)   等价于   !a && !b
```

AP 常考的翻译题：「不是（及格且出勤够）」= 「不及格**或**出勤不够」。记口诀：**非进括号，且或互换**。

## 每日一虫 🐛：想「都」却写成了「或」

看这段代码：

```java
// 想判断两个成绩 pass1、pass2 是否都及格（都 ≥ 60）
if (pass1 >= 60 || pass2 >= 60) {
    System.out.println("两人都及格");
}
```
