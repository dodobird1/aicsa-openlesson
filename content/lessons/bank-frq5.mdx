## 官方风格评分标准（Scoring Guidelines）

**Question 5 — 共 7 分（part a 3 分 + part b 4 分）**

### Canonical solution（标准答案，供对照）

```java
// part (a)
public static boolean hasRun(String word)
{
    for (int i = 0; i < word.length() - 1; i++)
    {
        if (word.substring(i, i + 1).equals(word.substring(i + 1, i + 2)))
        {
            return true;
        }
    }
    return false;
}

// part (b)
public static String buildList(String items)
{
    String[] parts = items.split(" ");
    String result = "";
    for (int i = 0; i < parts.length; i++)
    {
        result += (i + 1) + "." + parts[i];
        if (i < parts.length - 1)
        {
            result += " ";
        }
    }
    return result;
}
```

### Part (a)：hasRun — 3 分

| # | Scoring Criteria | Decision Rules | 分 |
| --- | --- | --- | --- |
| 1 | 遍历 word 的**相邻字符对**（访问位置 i 与 i+1） | 仍可得分：用下标循环或「取当前字符与前一字符比」的等价组织方式。不得分：循环条件写成 `i < word.length()`（最后一轮 i+1 越界抛异常，导致部分输入崩溃） | 1 |
| 2 | 相邻字符对的相等比较（所有 String 方法调用语法有效） | 仍可得分：单字符 substring 用 `==` 比较的写法（本题语境可等价接受） | 1 |
| 3 | 命中返回 true、全程未命中返回 false，对包括单字符在内的全部输入正确 **(algorithm)** | 不得分：单字符输入越界崩溃；返回了相反的 boolean；命中后不返回导致结果依赖后续逻辑出错 | 1 |
| | **Part (a) 小计** | | **3** |

### Part (b)：buildList — 4 分

| # | Scoring Criteria | Decision Rules | 分 |
| --- | --- | --- | --- |
| 4 | 把 items 拆分成单词并访问每一个（split 或遍历均可） | 仍可得分：用 indexOf 循环逐段切分的等价写法 | 1 |
| 5 | 编号从 1 开始且与单词位置一一对应 | 不得分：编号从 0 开始；编号与单词错位 | 1 |
| 6 | 拼接格式正确：`编号.单词` 相邻项之间单个空格分隔 | 仍可得分：先统一追加空格再去除首/尾空格的等价实现；或最终字符串末尾多一个空格（多数阅卷接受，判卷时按「结构清晰传达意图」处理）。不得分：编号与单词之间用了空格而非点 | 1 |
| 7 | 返回构建完成的字符串 **(algorithm)** | 不得分：打印而不返回；返回了 null；单词内容被修改 | 1 |
| | **Part (b) 小计** | | **4** |

**Scoring Notes**：part (a) 的「与前一字符比较」变体（从 i = 1 开始、比较 i 与 i−1）同样有效，边界相应移动但不得越界；part (b) 若不用 split 而用 `indexOf(" ")` 手工切段，只要单词与编号对齐即可得分。两个方法相互独立，一半未写不影响另一半。
