## 官方风格评分标准（Scoring Guidelines）

**Question 3 — 共 5 分（part a 2 分 + part b 3 分）**

### Canonical solution（标准答案，供对照）

```java
// part (a)
public int countCheapHardcovers(double maxPrice)
{
    int count = 0;
    for (BookInfo b : shelf)
    {
        if (b.isHardcover() && b.getPrice() <= maxPrice)
        {
            count++;
        }
    }
    return count;
}

// part (b)
public void removePaperbacks()
{
    for (int i = shelf.size() - 1; i >= 0; i--)
    {
        if (!shelf.get(i).isHardcover())
        {
            shelf.remove(i);
        }
    }
}
```
