## Set-based 组：第 16、17 题共用下面这段代码（真实考试形式）

考虑以下 Playlist 类（**只有这两题用到它**）：

```java
public class Playlist
{
    private ArrayList<String> songs;

    public Playlist()
    { songs = new ArrayList<String>(); }

    public void addSong(String s)
    { songs.add(s); }

    /** Precondition: songs.size() > 0 */
    public String swapFirstLast()
    {
        return songs.set(0, songs.remove(songs.size() - 1));
    }
}
```
