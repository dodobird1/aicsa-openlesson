## 方法：让程序学会「做一件事」

你其实从第一课起就在用**方法**（method）了——`System.out.println("Hello, World!")` 就是一次方法调用。方法是打包好的一段功能，你不需要知道它内部怎么写，只要知道**怎么叫它干活**。

一个方法调用长这样：

```java
double root = Math.sqrt(25.0);   // 调用 Math 类的 sqrt 方法，传入 25.0，得到 5.0
```

拆开看：

- **方法名**：`sqrt`——它擅长的事；
- **参数**（argument）：括号里传给它的 `25.0`——干活的原料；
- **返回值**（return value）：它算完交回给你的 `5.0`；
- **点号**：`Math.sqrt` 表示「Math 类里的 sqrt」——类名.方法名 是调用类方法的固定格式。

## Math 类：你的第一个工具箱

考试会提供 Java Quick Reference，Math 类只有 4 个方法（其中 abs 分 int、double 两个版本，在表上占 5 行），全部要熟到盲打：

| 方法 | 作用 | 例子 |
| --- | --- | --- |
| `Math.abs(x)` | 绝对值（int 和 double 各一版） | `Math.abs(-7)` → `7` |
| `Math.pow(base, exp)` | 乘方，返回 double | `Math.pow(2, 10)` → `1024.0` |
| `Math.sqrt(x)` | 平方根，返回 double | `Math.sqrt(2)` → `1.414…` |
| `Math.random()` | 随机数，范围 ≥ 0.0 且小于 1.0 | 每次不同 |

`Math.random()` 的取值范围是 AP 每年必考：**[0, 1)——含 0 不含 1**。要造指定范围的随机整数，用这套公式：

```java
int roll = (int)(Math.random() * 6) + 1;   // 掷骰子：1 到 6
```

原理：先乘 6 拉伸到 [0, 6)，取整得到 0 到 5，最后加 1 变 1–6——每个点数概率相等。公式先记住，第 14 课讲 cast 时你会真正看懂它。

## void 与返回值：干了活要不要交货

方法分两种，决定了你怎么调用它：

- **void 方法**：只干活不交货。`System.out.println(...)` 打印完就结束，没有返回值——你不能写 `int x = System.out.println("hi");`（编译错误）；
- **有返回值的方法**：干完活必须交货。`Math.sqrt(25)` 交回 `5.0`——**返回值必须被接住或立刻使用**：

```java
double d = Math.sqrt(25);              // ✓ 接住存进变量
System.out.println(Math.sqrt(25));     // ✓ 直接交给 println
if (Math.abs(x) < 0.001) { ... }       // ✓ 直接当条件用（第 16 课）
```

<Callout title="每日一虫预告">返回值被丢弃——调用了方法却不接它的返回值——是今天的虫。编译器**不报错**，程序照跑，但计算结果凭空消失。这种「安静的虫」比报错虫更值得警惕。</Callout>

## 对象初识：类的实例

`Math` 这样的类是**工具箱**（全是 static 方法，不用 new）。但 Java 世界里更多类是**蓝图**（blueprint）：类定义规格，**对象**（object）是按蓝图造出的实例。

你已经天天在用对象了——每个字符串都是 String 类的对象：

```java
String word = "APCSA";
System.out.println(word.length());   // 5 —— 对象.方法() 调用实例方法
```

「类 = 图纸，对象 = 按图纸盖的房子」——这个类比现在先立住，Unit 3 你会自己画图纸盖房。

## 每日一虫 🐛：消失的绝对值

看这段代码：

```java
int temperature = -3;
Math.abs(temperature);                          // 虫在这
System.out.println(temperature);                // 输出 -3，不是 3
```

<MultipleChoice id="objs-bug" question="上面的程序输出 -3。虫的病根是什么？" options={[{id:'a',label:'Math.abs 不能处理负数'},{id:'b',label:'Math.abs 的返回值被丢弃了，temperature 本身没有被修改'},{id:'c',label:'println 应该写在 Math.abs 之前'},{id:'d',label:'temperature 应该声明成 double'}]} answer={['b']} explanation="Math.abs(temperature) 计算出 3 并交回——但没人接住它，返回值直接蒸发。temperature 变量纹丝不动。修法：temperature = Math.abs(temperature);——让返回值有地方住。这是「返回值被丢弃」虫型的标准案例：编译不报错、运行不崩溃，结果就是不对。" />
