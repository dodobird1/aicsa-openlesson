## Part (a)：写构造器

构造器用 helper 方法 `getNextSong` 从 `firstSong` 出发把播放列表拼接出来：把 `firstSong` 存进 `playlist`，然后不断调用 `getNextSong`（传「当前最后一首歌」），把返回的新歌名以**单个空格**接在 `playlist` 末尾，直到 `getNextSong` 返回 `null`。同时统计歌曲总数存进 `numSongs`。

示例：`getNextSong` 依次返回——

| 调用 | 返回值 |
| --- | --- |
| `getNextSong("Sunrise")` | `"Highway"` |
| `getNextSong("Highway")` | `"Gold"` |
| `getNextSong("Gold")` | `null` |

那么 `new PlaylistBuilder("Sunrise")` 应使 `playlist` 为 `"Sunrise Highway Gold"`、`numSongs` 为 `3`。

## 官方风格评分标准（Scoring Guidelines）

**Question 1 — 共 7 分（part a 4 分 + part b 3 分）**

### Canonical solution（标准答案，供对照）

```java
// part (a)
public PlaylistBuilder(String firstSong)
{
    playlist = firstSong;
    numSongs = 1;
    String last = firstSong;
    String next = getNextSong(last);
    while (next != null)
    {
        playlist += " " + next;
        numSongs++;
        last = next;
        next = getNextSong(last);
    }
}

// part (b)
public int countLongSongs(int minLength)
{
    String[] songs = playlist.split(" ");
    int count = 0;
    for (String s : songs)
    {
        if (s.length() >= minLength)
        {
            count++;
        }
    }
    return count;
}
```

### Part (a)：构造器 — 4 分

| # | Scoring Criteria | Decision Rules | 分 |
| --- | --- | --- | --- |
| 1 | 对**当前最后一首歌**调用 getNextSong | 不得分：任何错误的 getNextSong 调用（如始终传 firstSong，或传值与最近加入的歌无关） | 1 |
| 2 | 循环持续到没有更多歌曲（null 判断正确） | 不得分：与 null 的比较写反，或错误地与空串比较 | 1 |
| 3 | 在循环内递增歌曲计数 | 仍可得分：没有初始化计数（只要递增发生在循环上下文中） | 1 |
| 4 | playlist 由 startingWord 与各返回歌名以单个空格正确构建，**且**计数被正确赋给 numSongs **(algorithm)** | 不得分：未初始化 playlist；首/尾多出空格；计数结果错误 | 1 |
| | **Part (a) 小计** | | **4** |

### Part (b)：countLongSongs — 3 分

| # | Scoring Criteria | Decision Rules | 分 |
| --- | --- | --- | --- |
| 5 | 遍历/拆分 playlist，访问每一个歌名 | 仍可得分：单词循环里提取长度的写法有缺陷 | 1 |
| 6 | 正确计算每个歌名的长度并与 minLength 比较（含等于；所有 String 方法调用语法有效） | 不得分：比较缺少等于（写成了 >） | 1 |
| 7 | 返回满足阈值的歌名计数 **(algorithm)** | 不得分：修改了 playlist；返回的另有其物 | 1 |

**Scoring Notes**：用 `split(" ")` 逐词、或用 `indexOf(" ")` 逐段切分、或按下标遍历 playlist 的写法均为有效解，按本表同判；计数用局部变量而未立即赋给字段的情况按第 3 点规则处理。逐点独立判分——第 5 点的缺陷不影响第 6、7 点得分。
