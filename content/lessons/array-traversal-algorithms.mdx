## 模板迁移：只换一个字

Unit 2 你在「1 到 n 的整数」上练熟了五大模板。搬进数组，结构分毫不变，唯一的变化：**操作对象从循环变量 i 变成元素 a[i]**：

```java
// 计数模板 · 整数版              // 计数模板 · 数组版
int count = 0;                    int count = 0;
for (int n = 1; n <= 100; n++)    for (int i = 0; i < a.length; i++)
    if (n % 7 == 0)                   if (a[i] % 7 == 0)
        count++;                          count++;
```

对照着读一遍——**左眼看到的骨架和右眼一模一样**。这就是模板的价值：认出模板，循环头和骨架直接默写。

## 求和与最值：初值的新学问

```java
// 求和
int total = 0;
for (int i = 0; i < a.length; i++) {
    total += a[i];
}

// 最大值：数组时代，初值直接用第一个元素
int max = a[0];
for (int i = 1; i < a.length; i++) {    // 从 1 开始：第 0 个不用跟自己比
    if (a[i] > max) {
        max = a[i];
    }
}
```

最值初值**从 Integer.MIN_VALUE 升级为 a[0]**：用真实元素当擂主，永不踩「假冠军」虫（负数数组的救星），还省一次比较——注意循环从 `i = 1` 起步。

## 查找：返回位置

```java
// 返回 target 的下标；不存在返回 -1
public static int find(int[] a, int target) {
    for (int i = 0; i < a.length; i++) {
        if (a[i] == target) {
            return i;      // 命中即返回位置
        }
    }
    return -1;             // 哨兵：全数组无此值
}
```

数组版查找的返回值升级成了**位置**——它比「有没有」信息更多（知道在哪），-1 惯例不变。

## for-each：只读巡游

遍历还有种简洁写法——**for-each 循环**（增强 for）：

```java
for (int value : a) {        // 读作：对 a 里的每个 value
    System.out.println(value);
}
```

没有索引、没有越界风险，读起来像英语。但它有两条硬限制：

1. **只读不写**：循环里改 value 不影响数组（value 是副本）；
2. **没有下标**：需要位置（比如查找、交换）时用不了。

口诀：**要看不要改、不要位置，才用 for-each**。

## 每日一虫 🐛：倒着走也别越界

```java
int[] a = {5, 4, 3, 2, 1};
// 想倒序打印
for (int i = a.length; i >= 0; i--) {
    System.out.println(a[i]);
}
```
