## 构造器：对象的出生证明

构造器（constructor）三个识别特征：**与类同名、没有返回类型（连 void 都没有）、new 时自动执行**。它的唯一使命：让对象一出生就状态完整。

```java
public class Student {
    private String name;
    private int score;

    public Student(String givenName, int givenScore) {
        name = givenName;
        score = givenScore;
    }
}
```

## 重载：一个类多张出生证明

**方法重载**（overload）：同名方法、参数不同，编译器按你传入的参数自动挑版本。构造器也能重载——给无名学生一张默认出生证明：

```java
public Student(String givenName, int givenScore) { ... }   // 两参版

public Student() {                                          // 无参版：重载
    name = "未命名";
    score = 0;
}
```

`new Student("小明", 90)` 走两参版，`new Student()` 走无参版——选哪个只看参数。

## this：当参数和字段撞名

更地道的写法是让参数直接叫 `name`——但这样它和字段 `name` 撞名了。`this` 用来区分：**this.name 是字段，不带 this 的 name 是参数**：

```java
public Student(String name, int score) {
    this.name = name;      // 把参数 name 装进这个对象的字段 name
    this.score = score;
}
```

这是 AP 真题里最常见的构造器写法，必须读得像读中文一样顺。原则：参数名和字段名相同时，赋值左侧必须带 this。

## 封装：数据藏起来，门口设安检

private 字段外界摸不到，那怎么读、怎么改？——开两扇**门**：

```java
public String getName() {          // getter：只读通道
    return name;
}

public void setScore(int newScore) {   // setter：带安检的写入通道
    if (newScore >= 0 && newScore <= 100) {
        score = newScore;              // 合法才放行
    } else {
        System.out.println("分数必须在 0 到 100 之间，已拒绝修改");
    }
}
```

这就是**封装**（encapsulation）的完整形态：字段 private + 方法把关。`setScore(-50)` 会被当场拒绝——上一课说的「防线」，今天落地。

## 不写构造器会怎样：默认值

一个字段如果从未被赋值，Java 悄悄给默认值：**int 是 0、double 是 0.0、boolean 是 false、引用类型是 null**。写了构造器却漏给某个字段赋值，它也拿默认值出场——这就是今天的虫。

## 每日一虫 🐛：漏初始化的字段

```java
public class Book {
    private String title;
    private int pages;

    public Book(String t) {
        title = t;          // 只初始化了 title
    }

    public void report() {
        System.out.println(title + " 有 " + pages + " 页");
    }
}

// 别处：new Book("Java 入门").report();
```
