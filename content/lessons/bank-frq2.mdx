## 题目说明（考试真实格式）

**Question 2: Class Design**（建议限时 22 分钟）

你要**写出完整的 `ParkingGarage` 类**——它代表一个自动化停车库。

- 构造器接收两个参数：`int spaces`（总车位数，假定 ≥ 0）和 `double rate`（每辆车每小时费用，假定 > 0.0）；
- `ParkingGarage` 对象初始为空（已停车 0 辆）；
- 类包含 `admit` 方法：参数 `int cars` 表示一批要进场的车辆数（假定 > 0）。

`admit` 的行为：

- 若车库剩余车位**足够**（剩余 ≥ cars）：把这批车计入已停车数，**批号从 1 开始、每成功一批加 1**，返回一个字符串，格式为 `Batch number 批号, fee $费用`，其中费用 = cars × rate；
- 若剩余车位**不足**：返回 `Garage full`——此时已停车数不变、不产生批号。

以下示例的调用序列发生在 `ParkingGarage` 类之外的另一个类里：

| 语句 | 返回值 | 说明 |
| --- | --- | --- |
| `ParkingGarage g1 = new ParkingGarage(20, 2.5);` | （无） | 建库：20 个车位，每车每小时 $2.5 |
| `s = g1.admit(4);` | `"Batch number 1, fee $10.0"` | 4 × 2.5 = 10.0；剩 16 位 |
| `s = g1.admit(18);` | `"Garage full"` | 18 > 16，不入场、不计批号 |
| `s = g1.admit(16);` | `"Batch number 2, fee $40.0"` | 16 × 2.5 = 40.0；剩 0 位 |
| `ParkingGarage g2 = new ParkingGarage(5, 3.0);` | （无） | 新车库，批号重新从 1 计 |
| `s = g2.admit(5);` | `"Batch number 1, fee $15.0"` | 5 × 3.0 = 15.0；剩 0 位 |

写出的类必须满足全部规格并与示例表一致（注意批号是**每个车库对象自己**的计数）。

## 官方风格评分标准（Scoring Guidelines）

**Question 2 — 共 7 分（单 part）**

### Canonical solution（标准答案，供对照）

```java
public class ParkingGarage
{
    private int totalSpaces;
    private int occupied;
    private double rate;
    private int batchCount;

    public ParkingGarage(int spaces, double r)
    {
        totalSpaces = spaces;
        occupied = 0;
        rate = r;
        batchCount = 0;
    }

    public String admit(int cars)
    {
        if (cars > totalSpaces - occupied)
        {
            return "Garage full";
        }
        occupied += cars;
        batchCount++;
        return "Batch number " + batchCount + ", fee $" + (cars * rate);
    }
}
```

### Scoring Criteria 与 Decision Rules

| # | Scoring Criteria | Decision Rules | 分 |
| --- | --- | --- | --- |
| 1 | 声明类头 `class ParkingGarage` | 不得分：类声明为 private；类外出现无关代码 | 1 |
| 2 | 声明**private** 实例变量，类型恰当（总车位 int、已停车数 int、费率 double、批号 int） | 不得分：任何实例变量声明为 static；变量声明在类外 | 1 |
| 3 | 声明构造器头 `ParkingGarage(int ___, double ___)` | 不得分：构造器声明为 private | 1 |
| 4 | 构造器为全部实例变量赋正确初值（含 occupied 为 0、批号计数为 0） | 仍可得分：批号从 1 起初始化，只要首次成功的字符串中批号正确 | 1 |
| 5 | 声明方法头 `String admit(int ___)` | 不得分：方法名不叫 admit；声明为 public 以外的访问级别 | 1 |
| 6 | 判断剩余车位、更新已停车数、更新批号，两种消息构建正确 **(algorithm)** | 仍可得分：未返回消息（第 7 点单独判）；字符串字面量有轻微拼写差但两个部分都在。不得分：未处理装不下的情形；两种消息都构建正确却返回了别的 | 1 |
| 7 | 返回按规格构建的字符串 | 仍可得分：返回的消息内容有误（返回行为本身正确）。不得分：返回不含任何计算的单字面量；返回非 String 值；某些路径没有返回 | 1 |
| | **Total** | | **7** |

**Scoring Notes**：先判失败再更新、或先更新后判（只要状态语义正确）均可；「剩余车位」写成 `totalSpaces - occupied` 或等价表达式均可；批号是每个对象自己的实例变量——两个车库的批号互不影响，若写成 static 则第 2 点与第 6 点均受影响（static 使状态共享，示例 g2 从 1 重新计数的验证失败）。
