## 从三要素到 for：把重复写进一行

要让程序重复做事，必须同时说清三件事——这就是**循环三要素**：从哪开始（**初始化**）、什么时候继续（**继续条件**）、每轮结束怎么变（**更新**）。

继续条件靠比较两个数，结果只有真或假：

| 写法 | 读法 | `i` 等于 5 时 |
| --- | --- | --- |
| `i < 5` | 小于 | 假，5 这一轮不做 |
| `i <= 5` | 小于或等于 | 真，5 这一轮还做 |
| `i > 5` | 大于 | 假 |
| `i >= 5` | 大于或等于 | 真 |
| `i == 5` | 两个数相等 | 真 |

单独一个 `=` 是把右边的值存进左边。要问「相不相等」，写两个等号 `==`。`i <= 5` 读成：i 比 5 小，或者正好等于 5，都继续；i 变成 6 就停。并且、或者、非留到后面的布尔课。这一课的条件只用上面这五种比较。

求 1 到 5 的和，把三件事分开写，就是 `while`（当条件为真就继续做）。后面有一整课专门讲它，这里先把它当成 for 的展开图：

```java
int total = 0;
int i = 1;              // 要素一：初始化
while (i <= 5) {        // 要素二：继续条件
    total += i;
    i++;                // 要素三：更新
}
```

三件事分散在三个地方，读代码的人得自己拼。Java 提供了一个把三要素**打包进一行**的写法，这就是 for 循环：

```java
int total = 0;
for (int i = 1; i <= 5; i++) {
    total += i;
}
```

功能完全一样。那为什么要学 for？因为当循环「有明确的起点、终点、步长」时，for 把三要素集中在视线的一行里——**读代码的人一眼就能数出循环几次**。这正是 MCQ 里「这段代码输出什么」类题目的解题入口。

## for 头解剖：执行的先后顺序

```java
for (int i = 1; i <= 5; i++) { ... }
//     └──①───┘ └──②──┘ └③┘
```

| 编号 | 部分 | 执行时机 | 执行次数 |
| --- | --- | --- | --- |
| ① | `int i = 1` | 循环开始前，只执行一次 | 1 次 |
| ② | `i <= 5` | 每轮**进入循环体之前**判断，false 就退出 | **比循环体多 1 次**（最后一轮结束后还要再判一次，才知道该停） |
| ③ | `i++` | 每轮循环体执行**完毕之后** | 和循环体一样多 |

完整的一轮顺序是：**① → ② → 循环体 → ③ → ② → 循环体 → ③ → ② ……** 直到②判 false。注意 `i++` 在循环体之后才执行——所以循环体里第一次用时，`i` 还是初始值。

## off-by-one：小于还是小于等于

数错一次循环，是全人类 for 循环的第一大虫（它就是今天的每日一虫）。数循环次数的口诀：**「小于几就执行几次（从 0 开始），小于等于几也执行几次（从 1 开始）」**：

```java
for (int i = 0; i < 5; i++)    // 0,1,2,3,4   —— 5 次
for (int i = 1; i <= 5; i++)   // 1,2,3,4,5   —— 5 次
for (int i = 0; i <= 5; i++)   // 0,1,2,3,4,5 —— 6 次！
```

第三行就是经典 off-by-one：本想跑 5 次，实际跑了 6 次。防虫口诀：写完 for 头，**先在草稿上列出 i 的完整取值序列**，再写循环体。

## 倒序与步长

for 头三段都可以换，方向和步长都由你定：

```java
for (int i = 5; i >= 1; i--)      // 5,4,3,2,1 —— 倒序
for (int i = 2; i <= 10; i += 2)  // 2,4,6,8,10 —— 步长 2（只要偶数）
```

倒序时条件换成 `>=`、更新换成 `--`，其余不变——三要素换个方向而已。

## 每日一虫 🐛：一声不吭的倒计时

看这段代码：

```java
// 想打印 3、2、1 的倒计时
for (int i = 3; i <= 1; i--) {
    System.out.println(i);
}
```

<MultipleChoice id="for-bug-l1" question="这段「倒计时」的虫是什么？" options={[{id:'a',label:'方向反了：倒序时条件应写 i >= 1，现在 3 <= 1 一开始就是 false，一次都不会执行'},{id:'b',label:'步长错了：i-- 应该写成 i++'},{id:'c',label:'println 应该写成 print'},{id:'d',label:'int i = 3 应该从 1 开始'}]} answer={['a']} explanation="倒序循环的规则：起点大、终点小、条件用 >=、更新用 --。这里条件写成 i <= 1，第一轮判断 3 <= 1 直接为 false——循环体一次都不执行，程序安静地结束（还不报错！）。这种「不报错的虫」比编译错误更隐蔽，正是循环边界类虫型的代表。" />

<Callout title="L2 说病根">对今天的虫，合上选项口头说出：这只虫叫什么类型（循环边界/off-by-one 家族）？运行时会发生什么（一次都不执行、无输出、无报错）？修哪里（条件改为 i >= 1）？——说完整才算抓完。</Callout>
