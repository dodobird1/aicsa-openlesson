## 冲刺模块的 FRQ 三连

FRQ 共 4 题 90 分钟，建议每题 20 分钟、留 10 分钟机动。本课打前两题——它们合计 **14 分**，且全部建立在你已滚瓜烂熟的基本功上。

## Q1：Methods and Control Structures（7 分）

结构：Part A（4 分）考循环 + 条件 + 调用给定方法；Part B（3 分）考 String 方法。**真题风格示例**：

> **Part A**：实现 `countLetter(String word, String letter)`——返回 letter（单字符字符串）在 word 中出现的次数（区分大小写）。例：countLetter("banana", "a") 返回 3。
>
> **Part B**：实现 `reverse(String word)`——返回 word 的反向字符串。例：reverse("cat") 返回 "tac"。

**Part A 就是你写过的代码**（第 21 课 countLetter 原题）：

```java
public static int countLetter(String word, String letter) {
    int count = 0;
    for (int i = 0; i < word.length(); i++) {
        if (word.substring(i, i + 1).equals(letter)) {
            count++;
        }
    }
    return count;
}
```

**Part B 的倒序拼装**——从末尾往前，每格摘一个字符接到结果后面：

```java
public static String reverse(String word) {
    String result = "";
    for (int i = word.length() - 1; i >= 0; i--) {
        result += word.substring(i, i + 1);
    }
    return result;
}
```

两段代码涵盖 Q1 的全部套路：遍历骨架、substring 逐字符、条件命中、倒序循环、字符串累加（result +=）。**每一段都要能白纸默写**。

## Q2：Class Design（7 分）

第 31 课的答题五步法原样适用：圈名词→字段、圈动词→方法、全 private、构造器初始化全部、逐方法翻译。Q2 的分**最容易守**：字段与构造器约占 3 分，方法实现各占 1–2 分。
