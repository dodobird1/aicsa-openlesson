## 数组的烦恼，ArrayList 来解

P3 校园卡开三张卡用了三个变量；上一课你学会了用数组装它们——但数组**长度出生定死**：开第四张卡就得新建数组。真实世界里卡的数目天天变，你需要一个**会自己长大的数组**：ArrayList。

```java
ArrayList<String> names = new ArrayList<String>();
names.add("小明");     // 加一个，长度变 1
names.add("小红");     // 再加一个，长度变 2——不用预先报数
```

## 尖括号里装什么：Integer 的登场

`ArrayList<int>` 是**非法的**——尖括号里只能放引用类型。于是每种基本类型都有个「包装类」（wrapper class）表亲：

| 基本类型 | 包装类 |
| --- | --- |
| int | Integer |
| double | Double |

存 int 用 `ArrayList<Integer>`。放进去和取出来时 Java 自动转换（**装箱** autoboxing / **拆箱** unboxing），你只管当 int 用：

```java
ArrayList<Integer> scores = new ArrayList<Integer>();
scores.add(88);              // int 自动装箱成 Integer 存入
int first = scores.get(0);   // Integer 自动拆箱成 int 交给你
```

一句话：**尖括号写 Integer，用起来当 int**。

## 六个方法打天下（考场 Quick Reference 全表）

| 方法 | 作用 | 例 |
| --- | --- | --- |
| `list.size()` | 当前元素个数 | 加了 3 个就是 3 |
| `list.add(x)` | 追加到末尾 | `[a, b]` add c → `[a, b, c]` |
| `list.add(i, x)` | 插到下标 i，后面元素右移 | `[a, c]` add(1, b) → `[a, b, c]` |
| `list.get(i)` | 读下标 i 的元素 | 不删不改 |
| `list.set(i, x)` | 替换下标 i，返回旧值 | `[a, b]` set(0, z) → `[z, b]` |
| `list.remove(i)` | 删下标 i，后面元素左移，返回被删元素 | `[a, b, c]` remove(0) → `[b, c]` |

注意 ArrayList 的长度是 **size()（带括号）**——和数组的 length（无括号）、String 的 length() 凑成三兄弟，年年混考。
