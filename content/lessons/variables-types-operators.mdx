## 程序从「记住」开始

第 8 课的 Hello World 有个遗憾：它什么都不记得。上一课在给那段程序找虫。真正的程序需要**变量**（variable）——给一块内存起个名字，把值存进去、改掉、读出来：

```java
int score = 90;        // 声明一个 int 型变量 score，初始值 90
score = score + 5;     // 读出旧值 90，加 5，存回去——现在是 95
System.out.println(score);   // 输出 95
```

一行声明 = **类型 + 名字 + 初始值**。类型告诉 Java 这块内存存什么：

| 类型 | 存什么 | 例子 |
| --- | --- | --- |
| `int` | 整数 | `0`、`42`、`-7` |
| `double` | 小数 | `3.14`、`-0.5` |
| `boolean` | 真假 | `true`、`false` |

AP CSA 只用这三种基本类型（CED 边界声明：`long`、`short`、`byte`、`float`、`char` 都不考，见大纲附录 B）。

命名用 **camelCase**（小驼峰）：第一个单词小写，后续单词首字母大写，如 `studentScore`、`maxCount`。想存不允许修改的常量，加 `final`：`final int MAX_SCORE = 100;`。

## 算术运算符与第一个大坑

`+`、`-`、`*` 大多数时候如你所料。坑在**除法**：

```java
System.out.println(7 / 2);     // 输出 3，不是 3.5！
System.out.println(7 / 2.0);   // 输出 3.5
System.out.println(7 % 2);     // 输出 1（% 是取余数）
```

**两个 int 相除，结果还是 int，小数部分直接砍掉**（不是四舍五入）。只要除数或被除数里有一个是 double，结果就是 double。这个坑 AP 每年都考，记住口诀：**「int 除 int，砍小数；见 double，变精确」**。

`%`（modulus，取余）是第二个常用运算符，两个经典用途：

```java
int n = 123;
System.out.println(n % 2);       // 1 → 判断奇偶（1 为奇数，0 为偶数）
System.out.println(n % 10);      // 3 → 取个位数
```

## 溢出：整数的边界

`int` 能存的范围是 −2147483648 到 2147483647（即 `Integer.MIN_VALUE` 到 `Integer.MAX_VALUE`）。超过上限会怎样？**绕回最小值**，像里程表归零：

```java
int max = Integer.MAX_VALUE;
System.out.println(max + 1);     // 输出 -2147483648，没有报错！
```

这叫**溢出**（overflow）。AP CSA 不要求你背边界数字，但要求知道：`Integer.MAX_VALUE + 1` 的结果是 `Integer.MIN_VALUE`（CED Topic 1.5.B）。

## 复合赋值与自增

两个简写家族，考试读代码必备：

```java
int x = 10;
x += 5;    // 等价于 x = x + 5 → 15
x -= 3;    // 12
x *= 2;    // 24
x /= 5;    // 4（注意！24/5 整数除法砍小数）
x %= 2;    // 0

int count = 0;
count++;   // 等价于 count = count + 1 → 1
```

`++` 只用**后置**形式单独成句（`count++`）。前置 `++x` 和把自增嵌进表达式（如 `arr[x++]`）CED 明确不考，见到认识即可，不写。

## 每日一虫 🐛：平均分为什么是 3.0

看这段代码：

```java
int total = 17;      // 5 道题的总分
int count = 5;       // 题数
double avg = total / count;   // 想得到平均分 3.4
System.out.println(avg);      // 实际输出 3.0
```
