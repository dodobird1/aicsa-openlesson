<MultipleChoice id="bank-u3-q5" question={'考虑以下类。连续创建两个对象后，b.getId() 的返回值是什么？\n\npublic class IdGenerator\n{\nprivate static int nextId = 1;\nprivate int id;\npublic IdGenerator()\n{\nid = nextId;\nnextId++;\n}\npublic int getId()\n{ return id; }\n}\n\nIdGenerator a = new IdGenerator();\nIdGenerator b = new IdGenerator();'} options={[{id:'a',label:'1'},{id:'b',label:'2'},{id:'c',label:'0'},{id:'d',label:'编译错误，构造器不能访问 static 变量'}]} answer={['b']} explanation="nextId 是 static 变量，被所有对象共享：创建 a 时 a.id = 1，nextId 变 2；创建 b 时 b.id = 2。static 是类级的「大家共用的一个」，实例变量是每个对象自己的。" />

<MultipleChoice id="bank-u3-q6" question={'把实例变量设为 private、只通过公开方法读写，最主要的理由是？'} options={[{id:'a',label:'代码行数更少'},{id:'b',label:'外部无法直接塞进非法值（如负的年龄），修改必须经过方法校验；内部表示日后可以自由更换'},{id:'c',label:'private 变量的运行速度更快'},{id:'d',label:'private 会让变量自动变成 static'}]} answer={['b']} explanation="封装的两个价值：防呆（所有修改都过方法这道闸门，可以校验）和解耦（外部只依赖方法签名，内部实现随便改）。它不是性能优化，也不改变存储方式。" />

<MultipleChoice id="bank-u3-q7" question={'Point 类有 move(int x, int y) 方法（把坐标改为参数值）和 getX() 方法。以下代码段输出什么？\n\nPoint p1 = new Point(2, 3);\nPoint p2 = p1;\np2.move(5, 5);\nSystem.out.println(p1.getX());'} options={[{id:'a',label:'2'},{id:'b',label:'5'},{id:'c',label:'3'},{id:'d',label:'编译错误'}]} answer={['b']} explanation="p2 = p1 复制的是引用（住址），不是对象本身——p1 和 p2 现在指向同一个对象，通过 p2 的 move 改的就是那一个对象，p1 去看自然也是 5。这就是引用别名（aliasing，Topic 3.6）。" />

<MultipleChoice id="bank-u3-q8" question={'Box 类的四个方法头中，哪几个有编译错误？\n\nI. public Box() { size = 1.0; }\nII. public double getSize() { return size; }\nIII. public double setSize(double s) { size = s; }\nIV. public void reset() { size = 0; return size; }'} options={[{id:'a',label:'只有 III'},{id:'b',label:'只有 IV'},{id:'c',label:'III 和 IV'},{id:'d',label:'都没有错误'}]} answer={['c']} explanation="III 声明返回 double 却没有 return 语句——non-void 方法必须每条路径都返回值；IV 声明 void 却试图返回值——void 方法不能 return 东西。I（构造器没有返回类型，正确）和 II（正常返回）都没问题。non-void 必有 return、void 不返回，是一对镜像规则。" />

## 第二批：this、重载、传参与作用域

<MultipleChoice id="bank-u3-q9" question={'在构造器 public Cat(String name) { this.name = name; } 中，this.name 指的是什么？'} options={[{id:'a',label:'实例变量 name'},{id:'b',label:'参数 name'},{id:'c',label:'类名 Cat'},{id:'d',label:'一个 static 变量'}]} answer={['a']} explanation="参数名和字段名相同时，裸写 name 指参数（就近原则）；this.name 明确指「本对象的字段」。没有 this，赋值语句变成参数自己赋值给自己，字段永远是默认值。" />

<MultipleChoice id="bank-u3-q10" question={'Pizza 类有两个构造器：Pizza(String s) 和 Pizza(String s, int n)。new Pizza("L", 12) 调用的是哪个？'} options={[{id:'a',label:'双参数版本 Pizza(String, int)'},{id:'b',label:'单参数版本 Pizza(String)'},{id:'c',label:'两个构造器依次各调用一次'},{id:'d',label:'编译错误，一个类不允许两个构造器'}]} answer={['a']} explanation="重载解析看实参的个数和类型：给了 String 和 int 就匹配双参数版本。一个类可以有多个参数列表不同的构造器。" />

<MultipleChoice id="bank-u3-q11" question={'以下方法会怎样？\n\npublic class Dog\n{\nprivate String name;\nprivate static int count = 0;\npublic static void rename(String n)\n{\nname = n;\n}\n}'} options={[{id:'a',label:'编译错误'},{id:'b',label:'正常运行，修改调用对象的 name'},{id:'c',label:'运行时异常'},{id:'d',label:'自动修改所有 Dog 对象的 name'}]} answer={['a']} explanation="static 方法属于类、没有「当前对象」，而 name 属于每个对象——没有对象却要摸它的字段，编译器直接拒绝。这是 Topic 3.7 的明确考点：static 方法只能直接访问 static 成员。" />

<MultipleChoice id="bank-u3-q12" question={'Point 类有 move(int x, int y)（把坐标改为参数值）和 getX() 方法。以下代码段输出什么？\n\npublic static void bump(Point p)\n{\np.move(p.getX() + 1, p.getY());\n}\n\nPoint q = new Point(4, 4);\nbump(q);\nSystem.out.println(q.getX());'} options={[{id:'a',label:'4'},{id:'b',label:'5'},{id:'c',label:'编译错误'},{id:'d',label:'0'}]} answer={['b']} explanation="对象作为参数传递的是引用（住址的拷贝）——p 和 q 指向同一个对象，方法内的 move 永久生效。如果参数是 int，方法内改的只是副本，外面不变——对象与 primitive 的传参差异是 Topic 3.6 的核心。" />

<MultipleChoice id="bank-u3-q13" question={'以下代码段中调用 go() 后输出什么？\n\npublic class Test\n{\nprivate int x = 1;\npublic void go()\n{\nint x = 100;\nSystem.out.println(x);\n}\n}'} options={[{id:'a',label:'1'},{id:'b',label:'100'},{id:'c',label:'101'},{id:'d',label:'编译错误，变量不允许重名'}]} answer={['b']} explanation="方法内的局部变量会遮蔽（shadow）同名的实例变量：裸写 x 就近取局部变量 100。想拿字段得写 this.x。局部变量和字段重名合法，但读代码时要盯住作用域。" />

<MultipleChoice id="bank-u3-q14" question={'以下 setter 写法的最大价值是什么？\n\npublic void setAge(int a)\n{\nif (a >= 0)\n{\nage = a;\n}\n}'} options={[{id:'a',label:'挡住非法值（负年龄）'},{id:'b',label:'让 age 变量运行更快'},{id:'c',label:'Java 语法要求字段必须通过 setter 修改'},{id:'d',label:'让 age 自动变成 static'}]} answer={['a']} explanation="字段若声明为 public，任何外部代码都能塞进 -5；私有字段 + 带校验的 setter 保证 age 永远合法。这是封装「防呆」价值在代码层面的样子（Topic 3.8）。" />
