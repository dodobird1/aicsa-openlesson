## 历史遗留问题正式结案

第 10 课你记了口诀「int 除 int，砍小数」。现在学正式解法：让除法里**至少有一个 double**。两种手段：

```java
double a = 7 / 2.0;                  // 手段一：把常量写成小数
double b = (double) total / count;   // 手段二：cast 转换（本课主角）
```

## 自动转换：小水杯倒进大水杯

**int 到 double 是自动的**（拓宽，widening）：int 最多约 21 亿，double 的地盘大得多，怎么装都装得下：

```java
int n = 42;
double d = n;            // 自动，d 是 42.0
double avg = n / 2.0;    // int 遇上 double，整条运算升级为 double 运算
```

规则一句话：**混合运算中，只要有一方是 double，结果就是 double**。

## cast：大水杯倒进小水杯，自己动手

**double 到 int 必须显式转换**（缩窄，narrowing）——用 cast 运算符 `(int)`，并且它是**截断（truncate），不是四舍五入**：

```java
double price = 9.99;
int dollars = (int) price;      // 9 —— 小数直接砍掉，不是 10
int negative = (int) -3.7;      // -3 —— 向零截断
```

想要四舍五入？加 0.5 的经典技巧（Math.round 不在考场 Quick Reference 上，不考）：

```java
double x = 9.99;
int rounded = (int)(x + 0.5);   // 10 —— 正数的四舍五入
```

## cast 只贴着最近的一块

`(double)` 只作用于**紧跟它的那一个值**。这是本课最大的陷阱墙：

```java
int a = 3;
int b = 4;
System.out.println((double)(a + b) / 2);   // 3.5 —— 括号包住 a+b：先算 7，转 7.0，再除 2
System.out.println((double) a + b / 2);    // 5.0 —— 只转了 a 变 3.0；b/2 是整数除法得 2；3.0+2=5.0
```

两个式子只差一对括号，结果一个是 3.5、一个是 5.0。**cast 的括号包住谁，谁就被转换**——写 cast 时永远先问自己这句话。

## 溢出与精度：int 的天花板，double 的宿命

| 类型 | 范围与特性 |
| --- | --- |
| `int` | 约 −21.4 亿 到 +21.4 亿（`Integer.MAX_VALUE` / `MIN_VALUE`）；越界绕回，不报错 |
| `double` | 范围极大，但只有约 15–16 位有效数字，且有微小算术误差 |

```java
System.out.println(0.1 + 0.2);   // 0.30000000000000004 —— 浮点误差的宿命
```

AP 考两点就够：int 溢出绕回（第 10 课已见）；double 精度有限（CED Topic 1.5）。

## 解锁成就：看懂随机数公式

第 12 课背的公式，现在全通了：

```java
int roll = (int)(Math.random() * 6) + 1;
```

逐步执行：random 是 double（[0, 1)）→ 乘 6 仍是 double（[0, 6)）→ `(int)` 截断成 0–5 → +1 平移到 1–6。**cast 的括号必须包住整个乘法**：写成 `(int) Math.random() * 6` 会先把 random 截成 0，乘 6 永远得 0——每次都掷出 1，史上最烂骰子。

## 每日一虫 🐛：白干的 cast

看这两行（sum = 7，n = 2，都是 int）：

```java
double right = (double) sum / n;      // 3.5，正确
double wrong = (int) sum / n * 1.0;   // 虫在这行
System.out.println(wrong);
```
