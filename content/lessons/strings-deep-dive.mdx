## 字符串是一座字符的公寓

`String` 是一串字符（character）组成的对象。每个字符有自己的门牌号——**索引**（index），从 0 开始：

```text
字符串：  A  P  C  S  A
索引：    0  1  2  3  4
```

「APCSA」长度 5，索引最大 4——**length 是 5，最后下标是 4**，这个差 1 会陪伴你整个 AP 生涯。

## Quick Reference 上的 String 方法全表

考场上 Quick Reference 提供的 String 方法就这些，全要熟：

| 方法 | 作用 | 用 APCS A 举例 |
| --- | --- | --- |
| `s.length()` | 长度 | `"APCSA".length()` → `5` |
| `s.substring(from, to)` | 取索引 from 到 to−1 的子串 | `"APCSA".substring(1, 3)` → `PC` |
| `s.substring(from)` | 取从 from 到末尾 | `"APCSA".substring(3)` → `SA` |
| `s.indexOf(str)` | 找 str 首次出现的索引，找不到返回 −1 | `"APCSA".indexOf("CS")` → `2` |
| `s.equals(other)` | 内容是否相同 | `"AP".equals("AP")` → `true` |
| `s.compareTo(other)` | 按字典序比较 | 见下文 |

## 最重要的规则：substring 含头不含尾

`substring(1, 3)` 取索引 1 和 2，**不取 3**——和 for 循环 `i = 1; i < 3` 的范围一模一样。两个知识点在这里会师：

```java
String s = "APCSA";
System.out.println(s.substring(1, 3));   // PC（索引 1、2）
System.out.println(s.substring(2));      // CSA（索引 2 到末尾）
System.out.println(s.substring(2, 2));   // 空串 ""（合法！头尾相等就是空）
```

`compareTo` 记结论就够：**调用者排前面返回负数，相同返回 0，排后面返回正数**。考试只问「结果是负/零/正」，不问具体数值。

## equals 不是 ==

String 是对象，`==` 比较的是「是不是同一个对象」（住址），`equals` 比较的是「内容是否相同」（长相）。**比较字符串内容，永远用 equals**：

```java
String a = new String("AP");
String b = new String("AP");
System.out.println(a == b);        // false！两个不同对象
System.out.println(a.equals(b));   // true —— 内容相同
```

这是 AP CSA 的经典考点：两个内容相同、分别 new 出来的 String，用 `==` 比较是 false。

## 遍历字符串：substring(i, i+1) 取字符

考场 Quick Reference 上**没有** charAt 方法——所以逐字符处理字符串的标准写法，是用 substring 每次取一个字符：

```java
String word = "APCSA";
for (int i = 0; i < word.length(); i++) {
    String letter = word.substring(i, i + 1);   // 取索引 i 的那一个字符
    System.out.println(letter);
}
```

条件 `i < word.length()` 保证 i+1 最多等于 length——正好卡在合法边界内。这个模式请练到盲打。

## 每日一虫 🐛：越界的 substring

看这段代码：

```java
String s = "APCSA";
for (int i = 0; i <= s.length(); i++) {
    System.out.println(s.substring(i, i + 1));
}
```
