## 第一组：数组与二维（1–5 题）

<MultipleChoice id="u4r-q1" question="以下哪个表达式正确取得数组 int[] a 的长度？" options={[{id:'a',label:'a.length（字段，无括号）'},{id:'b',label:'a.length()'},{id:'c',label:'a.size()'},{id:'d',label:'length(a)'}]} answer={['a']} explanation="三兄弟各归其位：数组 a.length（无括号）、字符串 s.length()（有括号）、ArrayList list.size()。这组对照年年必考。" />

<MultipleChoice id="u4r-q2" question="执行 String[] names = new String[3]; 后（未存过值），names[0] 的值是？" options={[{id:'a',label:'空字符串'},{id:'b',label:'null'},{id:'c',label:'编译错误'},{id:'d',label:'0'}]} answer={['b']} explanation="默认值表在数组上照常生效：int 是 0、double 是 0.0、boolean 是 false、**引用类型（String、对象）是 null**。null 意味着「格子存在但没指向任何对象」——对它调方法会抛 NullPointerException。" />

<MultipleChoice id="u4r-q3" question={'以下代码的运行表现是？\n\nint[] a = {3, 6, 9};\nfor (int i = 0; i <= a.length; i++) {\n    System.out.println(a[i]);\n}'} options={[{id:'a',label:'打印 3、6、9 后，i = 3 时访问 a[3] 越界抛异常崩溃'},{id:'b',label:'打印 3、6、9 后正常结束'},{id:'c',label:'编译错误'},{id:'d',label:'打印 3、6、9、0'}]} answer={['a']} explanation="length 是 3，合法下标 0 到 2——条件带等号让 i 冲到 3，前三轮正常打印、第四轮当场越界。数组越界是运行时错误：编译无感、前三行输出正常，崩溃在最后一步——「看起来快跑完了才炸」是它的标志。" />

<MultipleChoice id="u4r-q4" question="int[][] g = new int[5][8]; 之后，g.length 和 g[0].length 分别是？" options={[{id:'a',label:'8 和 5'},{id:'b',label:'5 和 8'},{id:'c',label:'都是 5'},{id:'d',label:'都是 8'}]} answer={['b']} explanation="两种 length 各数一维：外层管行、取出一行后内层管列。双重遍历的循环条件就靠它们分工：外层 row < g.length、内层 col < g[row].length。" />

<MultipleChoice id="u4r-q5" question={'int[][] t = {{1, 2, 3}, {4, 5, 6}}; 表达式 t[1][2] 的值是？'} options={[{id:'a',label:'3'},{id:'b',label:'6'},{id:'c',label:'5'},{id:'d',label:'2'}]} answer={['b']} explanation="先行后列：t[1] 是 {4,5,6}，t[1][2] 是 6。从左往右读下标，每读一个就收窄一层。" />

## 第二组：ArrayList（6–10 题）

<MultipleChoice id="u4r-q6" question="ArrayList 的长度（元素个数）怎么取？" options={[{id:'a',label:'list.length'},{id:'b',label:'list.length()'},{id:'c',label:'list.size()'},{id:'d',label:'list.count'}]} answer={['c']} explanation="三兄弟速记：数组 length（字段）→ String length()（方法）→ ArrayList size()（方法）。AP 就爱在三个之间换着问。" />

<MultipleChoice id="u4r-q7" question={'list 为 [a, c]。执行 list.add(1, b) 后 list 是？'} options={[{id:'a',label:'[a, b, c]'},{id:'b',label:'[b, a, c]'},{id:'c',label:'[a, b]'},{id:'d',label:'[a, c, b]'}]} answer={['a']} explanation="带下标的 add 是插入不是替换（替换是 set）：后面元素集体右移、size 加一。选 c 混淆了 add 与 set；选 d 把插入当成了追加。" />

<MultipleChoice id="u4r-q8" question={'list 为 [10, 20, 30]。执行 list.remove(1) 后，list.get(1) 返回什么？'} options={[{id:'a',label:'20'},{id:'b',label:'30'},{id:'c',label:'null'},{id:'d',label:'抛异常'}]} answer={['b']} explanation="删除不留洞：后面的元素集体左移补位。remove(1) 删掉 20 后，30 滑到下标 1——get(1) 拿到 30。这个「左移」是边遍历边删除跳元素的病根。" />

<MultipleChoice id="u4r-q9" question="边遍历边删除 ArrayList 元素时，倒序遍历（从 size()-1 到 0）为什么安全？" options={[{id:'a',label:'因为倒序跑得快'},{id:'b',label:'因为删除只让被删元素右侧的元素左移'},{id:'c',label:'因为 remove 只在倒序时合法'},{id:'d',label:'因为倒序不会越界'}]} answer={['b']} explanation="正序的病根：删除后当前下标被下一个目标滑入、i++ 又跳过它。倒序把「受左移影响的区域」和「未处理区域」隔开了——这是结构性的安全，不是巧合。倒序删除七行骨架请保持可默写状态。" />

<MultipleChoice id="u4r-q10" question="声明存放 int 分数的 ArrayList，正确的写法是？" options={[{id:'a',label:'ArrayList<int>'},{id:'b',label:'ArrayList<Integer>'},{id:'c',label:'ArrayList<double>'},{id:'d',label:'intArrayList'}]} answer={['b']} explanation="基本类型进不了尖括号：int → Integer、double → Double。日常使用无感：add(88) 和 int x = get(0) 都是自动的。" />

## 第三组：查找、排序、递归、文件（11–15 题）

<MultipleChoice id="u4r-q11" question="二分查找能正确工作的前提是？" options={[{id:'a',label:'数组至少有 10 个元素'},{id:'b',label:'数组已按升序（或与查找逻辑一致的顺序）排好'},{id:'c',label:'数组是二维的'},{id:'d',label:'没有前提，永远正确'}]} answer={['b']} explanation="二分每一步都在用「有序」做推断：中间值偏大 → 目标必在左侧。无序时推断变瞎猜，目标可能被区间收缩悄悄甩掉——不崩溃、结果错。先有序，再折半。" />

<MultipleChoice id="u4r-q12" question="对 [4, 2, 9, 1] 执行选择排序的第一轮（找最小与下标 0 交换）后，数组是？" options={[{id:'a',label:'[1, 2, 9, 4]'},{id:'b',label:'[1, 2, 4, 9]'},{id:'c',label:'[2, 4, 9, 1]'},{id:'d',label:'[1, 4, 2, 9]'}]} answer={['a']} explanation="选择排序一轮 = 一次交换不是一串移位：只有 1 和 4 换位，2 和 9 原地不动——[1, 2, 9, 4]。选 b 是把一轮当全部轮次。模拟排序没有捷径，动手写交换。" />

<MultipleChoice id="u4r-q13" question={'按定义 fact(n)：n == 1 返回 1，否则返回 n * fact(n - 1)。fact(4) 的值是？'} options={[{id:'a',label:'24'},{id:'b',label:'10（4+3+2+1）'},{id:'c',label:'4'},{id:'d',label:'无限递归'}]} answer={['a']} explanation="展开：4 × 3 × 2 × fact(1) = 4 × 3 × 2 × 1 = 24。有 base case 不死循环；每层是乘不是加。递归题永远画展开图：下坡找基线，上坡算答案。" />

<MultipleChoice id="u4r-q14" question="读文件的循环条件为什么写 while (in.hasNext())？" options={[{id:'a',label:'让程序跑得快'},{id:'b',label:'每次读取前先确认还有数据'},{id:'c',label:'因为 for 循环读不了文件'},{id:'d',label:'为了关闭文件'}]} answer={['b']} explanation="hasNext 是读取的守卫：问一句「还有吗」再伸手。文件行数未知 + 读完即停 = 次数未知的循环 = while 的识别信号。全套礼仪：接到文件、hasNext 守卫、读完 close。" />

<MultipleChoice id="u4r-q15" question="以下哪个任务用 for-each（增强 for）**无法**正确完成？" options={[{id:'a',label:'打印 ArrayList 每个元素'},{id:'b',label:'把 int 数组每个元素乘 2 存回原位'},{id:'c',label:'统计列表中负数个数'},{id:'d',label:'求 2D 数组每行元素之和'}]} answer={['b']} explanation="for-each 铁律「只读不写」：循环变量是元素的副本，修改有去无回。要写回必须用带下标的传统 for（a[i] = a[i] * 2）。另外 for-each 遍历时增删元素通常会抛 ConcurrentModificationException；偶尔碰巧删到末尾元素会安静结束但结果仍错——只读巡游，别越界使用。" />
