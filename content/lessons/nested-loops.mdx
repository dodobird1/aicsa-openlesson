## 循环套循环

打印一行三个星你会（一个 for）。打印**三行**、每行三个星呢？——「每行」本身就是一个循环，套在外面：

```java
for (int i = 1; i <= 2; i++) {          // 外层：第几行
    for (int j = 1; j <= 3; j++) {      // 内层：这一行第几个星
        System.out.print("* ");
    }
    System.out.println();               // 一行结束，换行（注意在两个循环之间）
}
```

输出：

```text
* * *
* * *
```

读嵌套循环的口诀：**外层走行，内层走列**。外层每走一步，内层**完整地跑一整圈**。上面的程序执行顺序是：i=1 → j 跑完 1、2、3 → 换行 → i=2 → j 再跑完 1、2、3 → 换行。

注意 `println()` 的位置——它夹在两个循环**之间**（属于外层），每行结束才换行；放进内层就变成每颗星换一行。

## 追踪表：纸上的演算仪

嵌套循环一多，脑内模拟必然出错。**追踪表**（trace table）是 MCQ 的标准装备：外层变量一列、内层变量一列、输出一列，一行一行填：

| i | j | 输出（累计） |
| --- | --- | --- |
| 1 | 1、2、3 | `* * *` |
| 2 | 1、2、3 | `* * *`（换行后第二行） |

考试遇到嵌套循环输出题，**先画表再答题**——比盯着代码转脑子快而且准。

## 执行次数：外层 × 内层

外层跑 m 次、每次带动内层跑 n 次，循环体总共执行 **m × n** 次：

- 上面例子：2 × 3 = 6 颗星；
- 两个 10 次的循环嵌套：100 次。

内层条件还可以**依赖外层变量**——三角形模式：

```java
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= i; j++) {      // 内层次数随 i 变：第 1 行 1 颗，第 2 行 2 颗……
        System.out.print("*");
    }
    System.out.println();
}
```

输出是三角形，总次数变成 **1 + 2 + 3 = 6**（不再是我们熟悉的 3 × 3 = 9）。「依赖型嵌套」的次数要逐行累加，不能直接相乘——这是后面「效率直觉」一课的铺垫。

## 每日一虫 🐛：内层用错了变量

看这段想打印三角形的代码：

```java
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        System.out.print("*");
    }
    System.out.println();
}
```
