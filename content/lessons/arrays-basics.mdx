## 欢迎来到权重之王

Unit 4 占考试 **30–40%**，是全卷最大的板块。打头阵的是**数组**（array）：一个变量名管理一整排同类型的值。

还记得 P1 单词卡和 P3 校园卡的「复制三份」之痒吗？数组就是解药：

```java
// 没有数组：三张卡三个变量，三十张卡三十个变量
double balance1 = 20.0;
double balance2 = 50.0;
double balance3 = 5.0;

// 有数组：一张变量名管一排
double[] balances = new double[3];
balances[0] = 20.0;
balances[1] = 50.0;
balances[2] = 5.0;
```

## 创建数组的三种写法

```java
int[] scores = new int[5];                 // 写法一：new + 长度，元素先拿默认值
String[] names = {"小明", "小红", "小刚"};   // 写法二：花括号直接列出初始值
int[] copy = scores;                       // 写法三：赋值（注意——复制的是地址，别名！）
```

写法一造出的 5 个格子是**真实存在的**，只是还没放东西——默认值见下表。

## 索引与 length：从 0 数起

```text
数组：    88   92   79   65   90
索引：    [0]  [1]  [2]  [3]  [4]
```

- **索引从 0 开始**，最后一个元素的下标是 `length - 1`——和 String 一模一样；
- **length 是字段不是方法**：数组写 `scores.length`（**没有括号**），字符串写 `s.length()`（**有括号**）。AP 每年都考这对双胞胎的区别。

| | 数组 | String / ArrayList |
| --- | --- | --- |
| 长度 | arr.length（字段，无括号） | s.length() / list.size()（方法） |
| 长度可变吗 | 定死，创建时确定 | String 不可变；ArrayList 会自己长 |

## 默认值：空盒子里装着什么

`new int[5]` 的五个格子不是空的，装着默认值：

| 元素类型 | 默认值 |
| --- | --- |
| int | 0 |
| double | 0.0 |
| boolean | false |
| 引用类型（String、对象） | null |

## 越界：运行时才引爆的炸弹

访问不存在的索引（负数或大于等于 length），编译器**不吭声**，运行时抛 ArrayIndexOutOfBoundsException——程序当场崩溃：

```java
int[] a = {2, 4, 6};        // 合法索引只有 0、1、2
System.out.println(a[3]);   // 编译通过；运行时崩溃！
```

防御手段只有一个：**访问前默念「最大下标是 length − 1」**。

## 每日一虫 🐛：多跑一轮的循环

```java
int[] scores = {2, 4, 6};
for (int i = 0; i <= scores.length; i++) {
    System.out.println(scores[i]);
}
```
