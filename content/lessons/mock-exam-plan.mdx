## 收官一课

你已经走完了 48 课：三个 AI 学习阶段、四个考纲单元、四个项目、两场红队日、四场检测。这收官的知识课只做一件事——**把状态调到考场频率，然后漂亮地收尾**。

## 两场全真模考（隔三天各一场）

**模考流程**（严格照做，一次到位）：

1. Bluebook 官方 practice，完整两节连做：Section I 42 题 90 分钟 → 休息 5 分钟 → Section II 四题 90 分钟；
2. 环境：安静房间、桌面只留设备和水、手机在另一间屋；
3. **全程无 AI、无笔记、无 Quick Reference 纸条**——Quick Reference 只在 Bluebook 里查；
4. 考完立刻做三件事：批 MCQ（错题进 P4 的 bank.txt）、把 FRQ 答案发给评分官、按四个 unit 给错题分类。

## 错题本终审（用上你的 P4）

冲刺期复习不再学新东西，只做三件事：

1. **P4 打开**：按错因过滤，**概念混淆类**优先重做——它们是理解性问题，临考最易失分；
2. **虫库过一遍**：红队日积累的虫库每天翻三只，说病根三句话；
3. **骨架默写保持手感**：每天白纸手写两段（倒序删除、行最值、reverse、读文件——轮着来）。

## 考前一周清单

| 时间 | 做什么 |
| --- | --- |
| 考前 7–4 天 | 模考② + 复盘；错题本二刷（只重做仍错的） |
| 考前 3 天 | 通读 Java Quick Reference 一遍（附录 A 全表）；轻量手感：每天两段骨架默写 |
| 考前 2 天 | 不刷新题。翻错题本标题、虫库目录；睡够 |
| 考前 1 天 | 30 分钟轻复习（你最熟的笔记过一遍涨信心）；准备证件与设备；早睡 |
| 考试日 | 提前到场；深呼吸三次；MCQ 先易后难、FRQ 先写骨架——然后，享受它 |

<Callout title="考试日心法">

你已经把每个模板默写过、每只虫说透病理、在白纸上写过程序、在 Bluebook 里练过手感。考场遇到的每一类题，你都见过它的同类。**紧张是正常的，陌生是不存在的**。一句考前口诀：模板认脸、端点默念、先骨架后血肉、部分分也是分。

</Callout>

## 一个值得庆祝的句号

考完那天，做三件事：

1. **合上错题本**——28 周的虫库与错题，是你从零走到 5 分的完整证据链；
2. **打开你的 P4 错题本系统**，把「AP CSA 考试」作为最后一道题录进去：错因写「无」；
3. **庆祝**——认真那种。你学会的不只是 Java：是用 AI 加速学习而不被它代替、是拆解大项目的指挥术、是在虫群里逆流而上的耐心。这些会陪你去下一个 28 周。
