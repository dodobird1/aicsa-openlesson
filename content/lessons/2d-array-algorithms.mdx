## 三种必会操作

上一课的全表遍历是地基，Q4 在地基上盖三种楼：

### 操作一：行内最值（外层行、内层找擂主）

```java
// 找每一行的最大值所在列（Q4 高频变体）
for (int row = 0; row < grid.length; row++) {
    int maxCol = 0;
    for (int col = 1; col < grid[row].length; col++) {
        if (grid[row][maxCol] < grid[row][col]) {
            maxCol = col;               // 记的是位置不是值！
        }
    }
    System.out.println("第 " + row + " 行最大值在下标 " + maxCol);
}
```

### 操作二：列求和（内外层身份互换）

列求和的经典写法——**内层遍历行、外层固定列**（也可以外层行内层列累加进一个一维数组，两种都常见）：

```java
for (int col = 0; col < grid[0].length; col++) {
    int colTotal = 0;
    for (int row = 0; row < grid.length; row++) {
        colTotal += grid[row][col];     // 行变列定，竖着扫一列
    }
    System.out.println("第 " + col + " 列的和是 " + colTotal);
}
```

### 操作三：按条件找所在行（返回行下标）

```java
// 返回 target 所在的行下标；不存在返回 -1
public static int findRow(int[][] grid, int target) {
    for (int row = 0; row < grid.length; row++) {
        for (int col = 0; col < grid[row].length; col++) {
            if (grid[row][col] == target) {
                return row;             // 命中即返回这一行的下标
            }
        }
    }
    return -1;
}
```

## Q4 题型解剖（6 分）

FRQ 第四题固定是 **2D Array**：给一个类带二维字段，写方法处理表格。骨架与 Q3 同款——**方法操作字段、遍历骨架直接上**，只是循环变成两层。

## 每日一虫 🐛：行列下标交换

```java
int[][] grid = new int[3][4];      // 3 行 4 列
for (int i = 0; i < grid.length; i++) {
    for (int j = 0; j < grid[0].length; j++) {
        System.out.print(grid[j][i]);   // 虫：行列写反了
    }
}
```

<MultipleChoice id="td2-bug" question="这段代码的运行表现是？" options={[{id:'a',label:'正常打印，行列互换而已'},{id:'b',label:'崩溃：i 走到 0、j 走到 3 时访问 grid[3][0]'},{id:'c',label:'什么都不打印'},{id:'d',label:'编译错误'}]} answer={['b']} explanation="grid[j][i] 把列下标 j 当行号用：j 的合法范围是 0 到 3（列数 4），但合法行号只到 2——第一行的内层循环走到 j = 3 就撞墙崩溃。行数与列数相等的方阵里这个虫会隐身（恰好不越界但访问错位），行列不等才现形——又一个「不报错时更危险」的典范。修法：老老实实 grid[i][j]，行列各归其位。" />
