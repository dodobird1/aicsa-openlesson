## 题目说明（考试真实格式）

**Question 4: 2D Array**（建议限时 18 分钟）

`WeatherStation` 类维护一个二维数组，记录一周内各观测点的降雨量，部分声明如下：

```java
public class WeatherStation
{
    /** rain[r][c] 是第 r 天在观测点 c 测得的降雨量（毫米，非负） */
    private int[][] rain;

    /**
     * 返回总降雨量最大的观测点（列）下标。
     * Precondition: rain 不为 null 且不含 null 行；
     *               rain 至少有 1 行 1 列。
     * Postcondition: rain 不被修改。
     */
    public int wettestColumn()
    { /* to be implemented */ }

    /* There may be instance variables, constructors, and methods
       that are not shown. */
}
```

访问 `rain` 元素时，第一个下标是天（行）、第二个下标是观测点（列）。

总降雨量 = 该列所有行的读数之和。若多列并列最大，返回其中**任意一个**下标即可。

示例：`rain` 内容如下——

| | 观测点 0 | 观测点 1 | 观测点 2 |
| --- | --- | --- | --- |
| **第 0 天** | 3 | 5 | 1 |
| **第 1 天** | 0 | 4 | 2 |
| **第 2 天** | 6 | 2 | 0 |

列总和分别是 9、11、3——`wettestColumn()` 返回 `1`。

## 官方风格评分标准（Scoring Guidelines）

**Question 8 — 共 6 分（单 part）**

### Canonical solution（标准答案，供对照）

```java
public int wettestColumn()
{
    int bestCol = 0;
    int bestSum = -1;
    for (int c = 0; c < rain[0].length; c++)
    {
        int sum = 0;
        for (int r = 0; r < rain.length; r++)
        {
            sum += rain[r][c];
        }
        if (sum > bestSum)
        {
            bestSum = sum;
            bestCol = c;
        }
    }
    return bestCol;
}
```

**Scoring Notes**：非方阵输入是行列写反的照妖镜——验证时务必用一个行数 ≠ 列数的例子（如 3 天 × 4 观测点）。按列统计后比较、或先算出每列总和存进 int[] 再统一找最大，均为有效解；降雨量非负，`bestSum` 初值取 -1 配合严格 `>` 安全。
