## 先看考纲怎么说（罕见的好消息）

CED 对递归的边界声明写得明明白白：**只考「确定递归方法调用的结果」（trace），编写递归代码不在考试范围内**。所以本课目标只有一个：给你一段递归代码，你能一步步算出结果。

## 递归是什么：套娃的函数

**递归**（recursion）= 方法定义里调用自己。看最经典的阶乘：

```java
public static int fact(int n) {
    if (n == 1) {
        return 1;              // base case：不再套娃的出口
    }
    return n * fact(n - 1);    // recursive case：问题缩小一层，交给下一个自己
}
```

每个递归方法必有这两块：

- **base case（基线）**：直接返回、不再递归的出口——没有它就是无限套娃；
- **recursive case（递归步）**：把问题缩小一点（n − 1）再交给下一个自己。

## 三问法：追踪任何递归

拿到递归代码，依次问三个问题：

1. **参数怎么变？**（每层 n − 1，朝基线走）
2. **何时停？**（n == 1 触发 base case）
3. **每层返回什么、怎么组合？**（本层 n 乘以下一层的结果）

## 追踪 fact(4)：两层展开图

```text
fact(4)
  └─ 4 * fact(3)
        └─ 3 * fact(2)
              └─ 2 * fact(1)
                    └─ return 1        ← base case！开始回卷
              = 2 * 1 = 2
        = 3 * 2 = 6
  = 4 * 6 = 24                          ← 最终答案
```

追踪分两段：**一路压到 base case（下坡），再一层层乘回来（上坡）**。在纸上画出这个展开图，是 MCQ 递归题的标准解法。

两条考纲级认知，配上就能做题：

- 每一层递归都有**自己的一份参数和局部变量**（所以 n 在每层互不干扰）；
- **任何递归都能改写成循环**，反之亦然——考试两者都认。

## 每日一虫 🐛：没有出口的套娃

```java
public static int broken(int n) {
    return n * broken(n - 1);   // 虫：忘了写 base case
}
```
