## 费曼学习法为什么有效

物理学家费曼有个著名的方法：**如果你不能用简单的语言把一个概念讲给别人听，说明你还没真正学会它。**

「听懂了」和「会讲」之间隔着一道坎。上课听懂 = 识别（认识别人说的话）；自己会讲 = 提取（从空白开始重建知识）。考试考的是提取。费曼法就是逼你跨过这道坎。

AI 出现之后，费曼法有了一个完美搭档：**一个永远有空、永远不怕被你讲烦的听众**。

## 学概念的完整循环

这就是本课程学每一个新概念的固定流程（四步循环）：

1. **讲给你听**：让概念教练用类比 + 最小示例讲一遍（AI 的强项）；
2. **你复述**：合上材料，用自己的话讲回去给 AI 听（费曼核心步骤，不许偷看）；
3. **挑毛病**：让 AI 指出你复述里的遗漏、错误、含糊（AI 当裁判）；
4. **修正**：针对毛病重讲一遍，直到 AI 挑不出大错。

注意这个循环里 AI 干的是「讲解员」和「裁判」，而**最费力的「复述」永远由你完成**——这正是导师式用法在概念学习上的版本。

## 概念教练的固定输出结构

课程里的概念教练（concept-coach）每次讲解都遵循固定结构，你要知道怎么看它：

- **大白话 + 类比**：先把概念翻译成生活语言；
- **最小示例**：一段 5–15 行的代码，逐段说明；
- **中英术语表**：概念 × 英文术语对照（这是给 AP 全英文考试准备的）；
- **检验问题**：最后问你一个问题——这就是循环第 2 步的入口。

## 为什么从第一天就做中英对照

AP CSA 考试全英文。如果平时用「数组」思考、考场上再翻译成 array，每题多一次脑内翻译，42 道选择题就是 42 次额外负担。正确做法是**从第一天起概念和英文术语绑定记忆**：想到数组，脑内浮现的就是 array。

所以你的每个概念笔记都应该有英文术语列。概念教练每次都会给你这张表，抄进笔记。

## 概念笔记模板

每个概念一页，三栏：

| 栏目 | 写什么 |
| --- | --- |
| 概念 | 中英术语 + 一句话定义 + 类比 |
| 我的复述 | 合上材料后自己写的解释（第一版通常不完整，没关系） |
| AI 纠正 | 教练挑出的毛病 + 修正后的关键句 |

## 实战：用四步循环学第一个 Java 概念

热身开始——用这个循环学一个真正的 Java 概念：**变量（variable）**。你马上要在 Unit 1 大量使用它。
