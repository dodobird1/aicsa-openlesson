## 欢迎进入冲刺模块

理论全部学完，冲刺模块只做一件事：**把会的东西变成分数**。选择题占 **55%**——42 题、90 分钟、4 选 1，每一题价值约 1.3 分。

## 题型四分类

MCQ 万变不离四类，各有各的打法：

| 题型 | 识别 | 打法 |
| --- | --- | --- |
| 输出预测 | What is the output? | 纸上追踪变量表，别心算 |
| 代码补全 | Which code segment? | 先排除语法错的，再代入验证逻辑 |
| 错误定位 | Which line causes…? | 逐行当虫审，优先看边界与类型 |
| 概念直问 | Which statement is true? | 用 Quick Reference 级记忆直答 |

## 三条时间纪律

1. **预算 2 分钟/题**：单题超过 2.5 分钟立刻标记跳过（Bluebook 可标记回看），42 题的战场里，三道难题耗掉的时间等于六道送分题；
2. **先易后难**：第一遍扫过去把会的全收割，第二遍回头啃硬骨头；
3. **交卷前不留空**：4 选 1 没有倒扣，蒙也要蒙满（先排除明显错的再蒙，正确率翻倍）。

## 排除法实战心法

- 两个选项在说同一件事的变体 → 大概率都不对；
- 涉及边界的选项，拿最小案例代入（数组长度 1、n 为 0）立刻见分晓；
- 「绝对化表述」（always、never、must）多为诱饵——Java 的世界充满例外。
