**Question 4: 2D Array**（建议限时 18 分钟）

`Theater` 类维护一个座位的二维数组，部分声明如下：

```java
public class Theater
{
    private Seat[][] seats;

    /**
     * 返回行收入最高的行下标。
     * 一行的收入 = 该行所有已售出（"occupied"）座位的票价之和。
     * Precondition: seats 不为 null 且不含 null 元素；
     *               seats 至少有 1 行 1 列。
     * Postcondition: seats 不被修改。
     */
    public int highestRevenueRow()
    { /* to be implemented */ }

    /* There may be instance variables, constructors, and methods
       that are not shown. */
}
```

访问 `seats` 元素时，第一个下标是行、第二个下标是列。

若多行收入并列最高，返回它们中的**任意一个**行下标即可。

示例：`seats` 内容如下（每个元素第一个值是状态、第二个值是票价）——

| | 列 0 | 列 1 | 列 2 |
| --- | --- | --- | --- |
| **行 0** | occupied, 80 | empty, 80 | occupied, 120 |
| **行 1** | empty, 60 | empty, 60 | empty, 60 |
| **行 2** | occupied, 100 | occupied, 100 | empty, 100 |

则 `highestRevenueRow()` 的行为：

- 行 0 收入 = 80 + 120 = 200（空座不计）；行 1 = 0（全空）；行 2 = 200。
- 收入最高为 200，行 0 与行 2 并列——返回 `0` 或 `2` 都算正确。

## 官方风格评分标准（Scoring Guidelines）

**Question 4 — 共 6 分（单 part）**

### Canonical solution（标准答案，供对照）

```java
public int highestRevenueRow()
{
    int bestRow = 0;
    int bestRevenue = -1;
    for (int r = 0; r < seats.length; r++)
    {
        int revenue = 0;
        for (int c = 0; c < seats[0].length; c++)
        {
            if (seats[r][c].getStatus().equals("occupied"))
            {
                revenue += seats[r][c].getPrice();
            }
        }
        if (revenue > bestRevenue)
        {
            bestRevenue = revenue;
            bestRow = r;
        }
    }
    return bestRow;
}
```

**Scoring Notes**：按行统计再比较、或先把每行收入算进一个 int[] 再找最大下标，均为有效解；`bestRevenue` 初值取 -1、0 或第 0 行实际收入都可行（票价非负，任选其一配合正确的比较方向都能得到合法答案）；题目明示并列返回任意下标——不要因为并列而写复杂分支，严格大于更新即可。
