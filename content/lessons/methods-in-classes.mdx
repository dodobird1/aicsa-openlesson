## 方法是类的动词

类 = 状态（字段）+ 行为（方法）。前两课造好了字段和构造器，这课把**方法**写精。

读一个方法先看**签名**（signature）四件套：

```java
public void bark() { ... }                    // 名字 bark、参数无、返回 void
public String getName() { ... }               // 返回 String
public void setScore(int newScore) { ... }    // 一个 int 参数
public boolean spend(double amount) { ... }   // 参数 double、返回 boolean
```

**访问修饰符 + 返回类型 + 方法名 + 参数列表**——签名是方法的身份证，AP 的题干经常只给签名让你补实现。

## 实例方法的超能力：直接摸到字段

Math.sqrt 这样的 static 方法是「公共工具」，谁调用都一样。而**实例方法**（不带 static）自带超能力：**能直接读写调用它的那个对象的字段**：

```java
public class Dog {
    private String name;
    private int age;

    public void birthday() {
        age = age + 1;                    // 直接摸到本对象的 age——不用参数传进来
        System.out.println(name + " 过生日，现在 " + age + " 岁");
    }
}
```

`d.birthday()` 时，方法里的 `age` 指的就是 **d 那只狗的 age**。这就是实例方法和 static 函数的本质区别：**它服务于一个具体的对象**。

## 方法调用方法

类内部，方法可以直接喊另一个方法帮忙（都服务于同一个对象）：

```java
public void birthday() {
    age = age + 1;
    celebrate();          // 直接叫同类里的另一个方法
}

public void celebrate() {
    System.out.println(name + " 开心得叫了一声！");
}
```

真实项目里方法越写越短、互相配合——每个方法只干一件小事（P3 项目你会大量用到）。

## void 与返回值的分工

- **改状态、打印** → `void`（干完不交货）；
- **算出一个答案** → 带返回类型，方法体里必有 `return`（干完必交货）。

一句口诀：**改东西用 void，问东西必有 return**。setter 用 void、getter 必返回——写错方向，编译器立刻找你。

<Callout title="考纲边界">每个类都是 Object 的子类。Object 自带 toString，Quick Reference 上列着它。把任意对象用 + 接到字符串后面时，Java 会调用这个 toString。考纲不要求你写 extends，也不要求重写 toString 或 equals。练习里写一个自己的汇报方法（如 report()）即可。</Callout>

## 每日一虫 🐛：static 手伸进了实例口袋

```java
public class Dog {
    private String name;

    public static void shout() {
        System.out.println(name + " 汪汪汪！");   // 虫在这
    }
}
```
