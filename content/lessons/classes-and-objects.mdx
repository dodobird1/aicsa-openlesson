## 欢迎来到 Unit 3

前两个单元你一直在**用**别人写好的类（Math、String）。Unit 3（考试权重 10–18%，FRQ 第二题的主场）你要**设计自己的类**——考试里这叫 Class Design，现实生活中这叫「造物」。

## 类是图纸，对象是房子

**类**（class）是图纸：规定这一类东西有哪些**状态**（数据）和**行为**（方法）。**对象**（object）是按图纸盖出的房子：每个对象有自己的数据，但共享同一套行为。

设计一只狗：

```java
public class Dog {
    private String name;    // 状态：名字
    private int age;        // 状态：年龄

    public Dog(String givenName, int givenAge) {   // 构造器：出生即登记
        name = givenName;
        age = givenAge;
    }

    public void bark() {                            // 行为：叫
        System.out.println(name + " 说：汪！");
    }

    public String getName() {                       // 行为：报上名字
        return name;
    }
}
```

读类的三问（考试读陌生类也用这三问）：

1. **状态有哪些**？——`private` 的实例变量（instance variable），每只狗一份；
2. **怎么出生**？——构造器（constructor），`new` 的时候跑；
3. **会做什么**？——方法，所有 Dog 共享同一套。

## new 的那一刻

```java
Dog a = new Dog("旺财", 3);
```

这行做了三件事：造一只狗（对象出现在内存里）→ 跑构造器填好 name 和 age → 把这只狗的**地址**交给变量 a。注意：**a 里存的不是狗，是狗的地址（引用，reference）**——a 是狗牌，不是狗。

## 使用你的类

```java
public class Kennel {
    public static void main(String[] args) {
        Dog a = new Dog("旺财", 3);
        Dog b = new Dog("小黑", 1);
        a.bark();                          // 旺财 说：汪！
        System.out.println(b.getName());   // 小黑
    }
}
```

两只狗各自有各自的 name 和 age——同一张图纸，两栋不同的房子。

## 每日一虫 🐛：两个名字，一只狗

看这段代码（main 写在 Dog 类内部，所以能直接碰 private 字段）：

```java
Dog a = new Dog("旺财", 3);
Dog b = a;        // 注意这行
b.age = 5;
System.out.println(a.age);
```
