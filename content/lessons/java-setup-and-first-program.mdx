## 为什么是 Java

AP Computer Science A 的考试语言是 **Java**——一门严格、啰嗦但结构清晰的语言。它的「啰嗦」对初学者反而是好事：每个概念都必须明明白白写出来，藏着掖不了。这门课的代码全部使用 **AP Java 子集**（AP CSA 考纲限定的语法范围），比完整 Java 简单得多。

从这节课起，你的电脑上要有一个能写、能跑 Java 的环境。考试那天你在 Bluebook 软件里**手打代码**，平时练习的打字手感、报错直觉，全靠现在开始积累。

## 第一步：安装 JDK

JDK（Java Development Kit）是编译和运行 Java 的工具包。安装 JDK 21（或 17）任一长期支持版均可：

- **macOS**：推荐到 [Adoptium](https://adoptium.net) 下载 `.pkg` 安装包（一路「继续」即可装好）；会用 Homebrew 的话 `brew install openjdk@21` 也行，但装完要按终端里 Caveats 提示补一步软链接，`java --version` 才能找到它；
- **Windows**：到 [Adoptium](https://adoptium.net) 下载 MSI 安装包，安装时勾选「将 JAVA_HOME 加入环境变量」。

装好后打开终端（Terminal / PowerShell），输入：

```bash
java --version
```

看到版本号（如 `openjdk 21.0.x`）就说明成功了。

## 第一个程序：Hello, World!

新建一个文件，文件名**必须**是 `HelloWorld.java`（Java 要求文件名和类名完全一致）：

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

运行它（IDEA 里点绿色三角，或终端里执行下面的命令）：

```bash
javac HelloWorld.java   # 编译：把 .java 源码变成 .class 字节码
java HelloWorld         # 运行：执行编译产物，输出 Hello, World!
```

屏幕上出现 `Hello, World!` 的那一刻，你就正式成为了一个会写 Java 的人。

## 逐行拆解这段程序

现在别管为什么这么写（AP 前几课只需要「记住骨架」），但每一**部分**是什么必须清楚：

- `public class HelloWorld` —— 定义一个**类**（class），名字叫 HelloWorld。类是 Java 组织代码的容器，AP CSA 的 Unit 3 会专门教你自己写类；
- `public static void main(String[] args)` —— **main 方法**：程序的入口。Java 从这里开始执行。`String[] args` 是命令行参数，考试中当作固定写法记住即可；
- `System.out.println("...")` —— 打印一行文字并换行。这是你未来三个月用得最多的一行代码；
- 每条语句结尾的 **分号** `;` —— Java 的「句号」。漏写分号是全人类 Java 初学者的第一大报错来源；
- 花括号 `{ }` —— 划定类和方法的边界，必须成对出现。

<Callout title="编译 vs 运行">`javac`（编译）负责检查你的代码是否符合 Java 语法，通过后生成 `.class` 文件；`java`（运行）才真正执行。**编译错误在先，逻辑错误在后**——这个区分在 Bluebook 考试里同样重要：打错一个字符，编译都过不了，更别说运行得分。</Callout>

## 报错地形图：新手的四种高频报错

写代码出错不是你不行的证据，是编译器在跟你说话。这四种报错你会遇到一百次：

```java
// 报错 1：缺少分号
System.out.println("Hi")   // error: ';' expected

// 报错 2：括号不配对（少了结尾的 }）
public class Oops {
    public static void main(String[] args) {
        System.out.println("Hi");
// error: reached end of file while parsing

// 报错 3：文件名和类名不一致（文件叫 Test.java 类叫 Hello）
// error: class Hello is public, should be declared in a file named Hello.java

// 报错 4：字符串没加引号
System.out.println(Hello);   // error: cannot find symbol
```

读报错的诀窍：**看第一行报错和它指的行号**，后面的连锁报错往往是一个根因引起的。找不到错在哪？这正是 AI 的用武之地——把报错原文和你的代码一起贴给教练。
